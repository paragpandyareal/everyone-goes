# Deploying the hosted demo (Render free + Neon free)


## 1. Neon (database)
1. Sign up at neon.tech (free plan). Create a project named `everyone-goes`, region US East.
2. Copy the **pooled** connection string (starts `postgresql://`, ends `?sslmode=require`).

## 2. Render (web service)
1. Render dashboard → New → **Blueprint** → pick the `everyone-goes` GitHub repo (Render needs access to the private repo). It reads `render.yaml`.
2. Fill the variables marked "sync: false": `DATABASE_URL` (the Neon string), the Trips and Cover Fund client IDs, secrets and emails, `PARENT_EMAILS`, `ANTHROPIC_API_KEY`, and `APP_BASE_URL` (the `https://everyone-goes-xxxx.onrender.com` address, add after the first deploy and redeploy).
3. `LINK_TABLE_KEY`, `APPROVAL_SIGNING_KEY` and `ADMIN_TOKEN` are generated by Render. Read `ADMIN_TOKEN` from the dashboard for the `/admin` page.

## 3. Webhooks (after the first deploy)
In developer.paypal.com, for each app add a webhook:
- Trips app → `https://<host>/api/webhooks/paypal/trips`, events: Invoicing invoice paid, updated, cancelled.
- Cover Fund app → `https://<host>/api/webhooks/paypal/coverfund`, events: Payment capture completed and denied, Payouts batch success, Vault payment token created and deleted.
Copy each webhook ID into `TRIPS_WEBHOOK_ID` and `COVERFUND_WEBHOOK_ID` on Render.

## 4. Seed the hosted demo
Open `https://<host>/admin`, paste `ADMIN_TOKEN`, and run steps 1 to 5. Pay the 8 parent invoices by hand from the links on that page.
